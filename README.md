# Lead Rescue AI — Service Lead Recovery Copilot

> Built for the Devpost **Build With AI: Basics** Hackathon.

Lead Rescue AI is a lightweight, AI-powered assistant designed for small service businesses (plumbers, HVAC technicians, electricians, and contractors) to identify high-intent leads slipping through the cracks and instantly generate personalized, ready-to-send follow-up messages.

---

## The Problem & The Unique Kernel

Service business operators receive dozens of inquiries through WhatsApp, website contact forms, phone calls, and direct messages. When prospects ask for pricing or service availability and go silent, busy operators on job sites lack the time to manually audit conversation histories or craft custom follow-up messages.

Rather than an overwhelming, expensive CRM or an unpredictable "black-box" AI system, **Lead Rescue AI** introduces:
1. **Explainable Deterministic Triage:** The system applies transparent, arithmetic time-and-status rules to identify which leads need attention and explains *why* (e.g., *"Quote unanswered for 4 days"*), grouping leads into actionable summary metrics without double-counting.
2. **Dual-Mode Follow-up Generation:** With one click, the operator generates a tailored revival message addressing the customer by their first name, referencing the requested service, and matching a chosen tone (*Friendly Check-in*, *Gentle Nudge*, or *Value-Focused*).
3. **Guaranteed Reliability:** Uses **Google Gemini** (`gemini-3.5-flash-lite`) when configured, and automatically switches to deterministic template fallbacks if an API key is missing or network access fails—explicitly displaying the generation source in the UI.

---

## Architecture & Technical Decisions

- **Backend:** Python 3.12 + FastAPI + Uvicorn. Exposes REST endpoints (`/api/leads`, `/api/triage`, `/api/generate`, `/api/health`) and mounts the static frontend.
- **AI Engine:** Google GenAI SDK targeting `gemini-3.5-flash-lite` (configurable via `GEMINI_MODEL`) with graceful deterministic fallbacks.
- **Frontend:** Single-page dashboard built with modern HTML5, CSS3, and Vanilla JavaScript—zero bundlers, zero npm dependencies, and instant local launch.
- **State & Security:** `GEMINI_API_KEY` is loaded strictly from environment configuration (`.env`, git-ignored) and never exposed to client-side code. Custom leads persist across page reloads via browser `localStorage`, with a 1-click **Reset Sample Data** button to restore the seeded demo at any time.

## Quickstart & Local Setup

### 1. Clone the repository & enter the folder
```bash
git clone https://github.com/saintsmile001/lead-rescue-ai.git
cd lead-rescue-ai
```

### 2. Set up a virtual environment & install dependencies
```bash
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Configure environment variables (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Add your Google Gemini API key if available:
```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
```
*(If no API key is set, the application operates 100% reliably in deterministic template fallback mode).*

### 4. Run automated tests
```bash
pytest -v
```
All 17 automated tests verify deterministic triage boundaries (72h, 48h, sub-hour boundaries, recent leads, closed statuses), metric subset consistency, and message generation.

### 5. Launch the application
```bash
python main.py
```
Open your browser and navigate to: **`http://127.0.0.1:8000`**

## 60-Second Demo Walkthrough

1. **Dashboard Overview:** Open `http://127.0.0.1:8000`. Notice the two top metric cards: **Leads Needing Follow-up** (2) and **High-Priority Leads** (1).
2. **Inspect Triage:** Scan the left column. Observe *Marcus Vance* flagged in red (`● Quote unanswered for 4 days`) and *Sarah Jenkins* in amber (`Inquiry inactive for 3 days`).
3. **Generate Follow-up:** Click on *Marcus Vance*. In the right panel, select **Friendly Check-in** (or **Value-Focused**) and click **⚡ Generate Follow-up Message**.
4. **Verify & Copy:** Notice the generated text and the source indicator (`● Generated by AI`). Edit any word in the text box and click **📋 Copy to Clipboard** to see the 2-second checkmark confirmation.
5. **Add a Custom Lead:** Click **+ Add Lead**, enter a new customer (e.g., Jennifer Martinez, Boiler Repair, Quote Sent, 4 days ago), and save. The summary metrics and list update dynamically.
6. **Reset:** Click **Reset Sample Data** to restore the initial seeded plumbing leads.
