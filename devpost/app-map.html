Lead Rescue AI — App Map

Architectural walkthrough and reusable technical takeaways for the Devpost Build With AI hackathon.

Plain-Language System Overview

Lead Rescue AI runs as a single local process. A Python FastAPI web server coordinates business logic and delivers a zero-build Vanilla JS single-page dashboard. The system has two primary responsibilities:

  • Deterministic Triage: Evaluates pipeline status and inactivity duration using clear, transparent rules to highlight leads slipping away.
  • Dual-Mode Revival Drafting: Calls Google Gemini (configured model gemini-3.5-flash-lite) to write natural, personalized follow-ups, with automatic fallback to local templates if offline or unconfigured.

Action Flow: "Generate Follow-up Message"

Code Tour: The 3 Core Stops

Stop 1: Triage Rules
triage.py → triage_single_lead()
Evaluates the elapsed inactivity duration and status. Assigns is_high_priority = True for quotes pending ≥ 72 hours, and computes the diagnostic explanation string (e.g., "Quote unanswered for 4 days").
Stop 2: Message Generation Engine
generator.py → generate_followup_message()
Attempts contextual AI generation using Google Gemini with tone guidelines and first-name extraction. If the API key is missing or a network error occurs, it instantly returns a deterministic template string with source: "fallback".
Stop 3: Interactive Dashboard Workshop
static/app.js → handleGenerateMessage()
Posts lead parameters to /api/generate, renders the response in an editable textarea, toggles the source badge, and manages the clipboard copy feedback.

"To Change This, Start Here"

Customize Follow-up Tones

Open generator.py and modify FALLBACK_TEMPLATES or the prompt instructions in generate_ai_message().

Tweak Urgency Thresholds

Open triage.py and adjust the hour thresholds (72h for high priority, 48h for inquiries).

Add Sample Leads

Open sample_data.py and add records to get_sample_leads().

Adjust UI Theme & Colors

Open static/style.css and update CSS variables under :root.

A Practice to Reuse on Future AI Projects

1. Separate Deterministic Business Logic from AI Generation: Rather than relying on an LLM to calculate elapsed dates and determine lead priority, we encapsulated triage in pure, testable Python arithmetic (triage.py). This made triage 100% predictable, lightning fast, and free from hallucinations.

2. Build the Fallback First: By creating and verifying high-quality deterministic templates before wiring up the live Gemini API, the application was never left vulnerable to rate limits, network outages, or missing keys.
