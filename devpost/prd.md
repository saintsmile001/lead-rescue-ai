# Lead Rescue AI — Product Requirements

A single-surface, AI-powered lead triage and follow-up assistant for small service businesses to spot cold leads and generate personalized outreach messages.
Source: `scope.md > The Unique Kernel`, `scope.md > Who It's For`, `scope.md > The POC Boundary`.

## The Core Journey
1. **Arrival & Overview:** The business operator opens the dashboard and immediately sees two high-level metric cards: **Leads Needing Follow-up** (total count of all leads requiring contact) and **High-Priority Leads** (the urgent subset among them), along with a preloaded list of realistic service leads.
2. **Deterministic Triage Inspection:** The operator scans the lead list. Leads needing attention are visually highlighted with status badges and plain-language diagnostic reasons (e.g., "Quote unanswered for 4 days", "Inquiry inactive for 48 hours").
3. **Lead Selection:** The operator clicks on any lead in the list. The right-hand panel immediately updates with the customer's full profile: name, service requested, current status, last contact timestamp, and interaction notes.
4. **Follow-up Configuration & Generation:** In the right panel, the operator selects a follow-up tone (Friendly Check-in [default], Gentle Nudge, or Value-Focused Follow-up) and clicks **"Generate Follow-up Message"**.
5. **Message Review & Source Verification:** The tailored message renders in an editable text area within 1–2 seconds. A clear badge explicitly shows whether the message was **"Generated by AI"** or **"Generated by Template Fallback"**.
6. **Edit & One-Click Copy:** The operator can make inline edits to the message and clicks **"Copy to Clipboard"**. The button momentarily updates to show visual confirmation ("Copied!"), ready for pasting into WhatsApp, SMS, or email.
7. **Lead Creation (Testing Flow):** The operator clicks the **"Add Lead"** button at the top of the list, enters a new lead via a simple modal form (Name, Service, Status, Last Contact Date, Notes), and submits. The list and metrics update immediately, applying the deterministic triage rules to the new entry.

## Features and Behavior

### 1. Deterministic Lead Triage & Urgency Rules
Source: `scope.md > The Core Loop`.
- The system evaluates each lead's `status` and `lastContactDate` against the current date/time:
  - **High Priority:** Lead status is `Quote Sent` AND elapsed time since last contact is $\ge 3$ days (72+ hours).
  - **Needs Follow-up:** 
    - Lead status is `New Inquiry` AND elapsed time is $\ge 48$ hours (2+ days), OR
    - Lead status is `Quote Sent` AND elapsed time is $\ge 2$ days (48 hours) and $< 3$ days (72 hours).
  - **No Follow-up Needed:** 
    - Leads with status `New Inquiry` or `Quote Sent` contacted $< 48$ hours ago, OR
    - Leads with status `Followed Up`, `Won`, or `Lost` (regardless of elapsed time).
- **Metric Definitions:**
  - *High-Priority Leads*: Count of leads matching the "High Priority" criteria.
  - *Leads Needing Follow-up*: Total count of all leads requiring attention (sum of "High Priority" leads + standard "Needs Follow-up" leads). High-Priority is an urgent subset of Leads Needing Follow-up, eliminating ambiguity and separate double-counting.
- **Diagnostic Reason generation:** Every flagged lead displays a clear reason string:
  - Examples: "Quote unanswered for 4 days", "Inquiry inactive for 48 hours", "Recent quote (sent yesterday)".

### 3. Dual-Mode Follow-up Message Generation
Source: `scope.md > The Unique Kernel`.
- When "Generate Follow-up Message" is triggered:
  - **Mode A (AI via Gemini):** When an API key is configured and request succeeds:
    - Backend generates a contextual message incorporating customer name, requested service, lead status, days inactive, notes, and selected tone.
    - Resulting message is conversational, personalized, and ready for WhatsApp/SMS.
    - UI displays badge: `● Generated by AI`.
  - **Mode B (Deterministic Template Fallback):** When API key is missing, empty, or network fails:
    - Deterministic templates generate a high-quality personalized message using string interpolation of lead parameters and the selected tone.
    - UI displays badge: `○ Generated by Template Fallback`.
    - Operates 100% offline with zero external dependencies.
- **Tone Profiles:**
  - *Friendly Check-in (Default):* Warm, polite inquiry asking if they have any questions about the service/quote.
  - *Gentle Nudge:* Direct, professional check-in noting schedule availability or upcoming slot holds.
  - *Value-Focused:* Highlights peace of mind, quality warranty, or bundled check-up without sounding aggressive.

### 4. Message Editing & Clipboard Copy
Source: `scope.md > The Core Loop`.
- Drafted message renders in an editable textarea for instant user tweaks.
- "Copy to Clipboard" button copies current textarea content to system clipboard.
- Visual feedback on button changes to "Copied!" with a checkmark for 2 seconds.

### 5. Manual Lead Creation & Lean State Management
Source: `scope.md > The POC Boundary`.
- "Add Lead" modal allows quick entry of custom leads to test triage and generation during the demo.
- Validates required fields (Customer Name, Service).
- **Lean State Persistence:** Stored in browser `localStorage` (or clean in-memory state initialized from the sample leads), avoiding heavy database setup while preserving edits across page refreshes.
- **Reset Sample Data:** A simple button resets the data back to the default 5 seeded leads at any time.

## States and Boundaries
- **First Use / Default State:** Loads immediately with realistic seeded plumbing leads; dashboard is immediately active and demonstrable.
- **Empty State:** If all leads are removed, displays: "No leads in your pipeline. Click 'Add Lead' or 'Reset Sample Leads' to get started."
- **Reset State:** "Reset Sample Data" returns the list to the initial 5 leads.
- **Missing API Key State:** Transparently falls back to template generation; never errors or blocks the user.
- **Security Boundary:** Frontend never handles raw Gemini API keys; any AI requests pass through a lightweight backend handler, keeping keys secure and out of client-side code.

## Product Decisions
- **Deterministic Triage vs. AI Triage:** Triage metrics and urgent flags use strict mathematical rules (status + days elapsed) to ensure 100% predictable, instant, and transparent results. AI is reserved strictly for creative, contextual message generation.
- **Single-Screen Split Dashboard:** Eliminates navigation latency and keeps the demo tight, enabling the full rescue loop (identify -> select -> generate -> copy) within a single 60-second video take.
- **Dual-Mode Generation Badge:** Solves the hackathon evaluation edge case where an evaluator tests without an API key; the app remains fully functional and explicitly communicates its operational mode.
- **Subset Metric Hierarchy:** "High-Priority Leads" is strictly a highlighted subset of the overall "Leads Needing Follow-up" total, ensuring clear, consistent numbers.

## What We're Building
- Single-screen responsive dashboard with metric cards, filterable lead list, and detail/message workshop panel.
- Deterministic lead triage evaluation logic with human-readable rationale tags.
- Gemini AI message generation with automatic deterministic template fallback.
- Tone selection (Friendly Check-in, Gentle Nudge, Value-Focused).
- Editable message box with one-click copy confirmation.
- Add Lead modal and lean Reset Sample Leads utility.
- Lightweight local state persistence without database complexity.

## Deferred From the POC
- Custom business profile configuration (custom company name, hours, phone number).
- Two-way WhatsApp Webhook synchronization.
- Automatic lead status advancement upon copying.
- Export to CSV/Excel.

## Possible Later Enhancements
- Direct Twilio / WhatsApp Cloud API dispatch.
- Multi-channel template variations (Email format vs. WhatsApp/SMS format).
- Follow-up outcome tracking (analyzing conversion by tone).

## Non-Goals
- Full CRM features (deals pipelines, customer invoicing, inventory tracking).
- Automated background message sending without operator approval.
- Multi-tenant user login and permissions.
- Database installation or migration overhead.

## Open Questions
- None blocking specification. All behavioral, visual, state, and security boundaries are established.
