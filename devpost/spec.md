# Lead Rescue AI — Technical Spec

## How This Works, In Plain Language
Lead Rescue AI is a lightweight web application that runs as a single local process. A Python FastAPI backend serves both the application's REST endpoints and its static web interface.

When the business operator opens the dashboard in their browser, the frontend initializes with a realistic set of seeded plumbing and home-service leads. The backend `triage.py` module serves as the single source of truth for deterministic triage rules, evaluating each lead's status and last-interaction timestamp to flag cold leads and categorize them into two summary counts: "Leads Needing Follow-up" and its urgent subset "High-Priority Leads".

When the operator selects a lead and clicks "Generate Follow-up Message", the browser sends the lead context (customer name, service requested, status, inactive duration, conversation notes, and chosen tone) to the backend `/api/generate` endpoint. The backend checks for a configured `GEMINI_API_KEY`. If present, it securely queries the configured Gemini model (configurable via `GEMINI_MODEL`, defaulting to `gemini-2.5-flash` or `gemini-1.5-flash`) to compose a tailored message; if the key is missing or the external API call fails, it immediately runs deterministic template generation. The backend returns both the generated text and a clear `source` flag (`"ai"` or `"fallback"`). The frontend displays the message in an editable text box with a visual badge indicating its origin, and offers a one-click copy button with clipboard confirmation. Any custom leads added by the user are stored in the browser's `localStorage` and can be reverted at any time using "Reset Sample Data".

## The Core Journey Through the System
1. **App Startup:** The operator launches `python main.py`. FastAPI mounts the static web frontend from `/static` and exposes REST API routes under `/api`.
2. **Initial Load & Triage:** The browser navigates to `http://127.0.0.1:8000`. The frontend JavaScript checks `localStorage`; if empty, it fetches default seeded leads (already triaged by the canonical backend engine) from `GET /api/leads`.
   - Implements `prd.md > The Core Journey` (Step 1) and `prd.md > 1. Deterministic Lead Triage & Urgency Rules`.
3. **Metric Calculation & List Rendering:** For each lead, triage evaluates elapsed days from `lastContactDate` to `now`. High Priority (`Quote Sent` $\ge 3$ days) and Needs Follow-up (`New Inquiry` $\ge 2$ days or `Quote Sent` 2–3 days) badges and diagnostic strings are rendered. Metric counters are computed such that High-Priority Leads is strictly an urgent subset of Leads Needing Follow-up.
   - Implements `prd.md > The Core Journey` (Step 2) and `prd.md > Screens and Layout`.
4. **Lead Selection:** Clicking a lead card sets the active lead state in JavaScript, rendering the lead's details, notes, and tone selector in the right-hand panel.
   - Implements `prd.md > The Core Journey` (Step 3).
5. **Message Generation Request:** The operator selects a tone (default: *Friendly Check-in*) and clicks "Generate Follow-up Message". JavaScript sends a `POST /api/generate` request with the lead payload and tone.
   - Implements `prd.md > The Core Journey` (Step 4) and `prd.md > 3. Dual-Mode Follow-up Message Generation`.
6. **Backend Processing & Security:** The FastAPI route inspects `os.environ.get("GEMINI_API_KEY")`.
   - If present: Backend calls the Gemini API (using `GEMINI_MODEL`, default `gemini-2.5-flash` or `gemini-1.5-flash`) with a structured prompt.
   - If missing/failed: Backend executes the deterministic template function.
   - Returns `{ "message": str, "source": "ai" | "fallback", "error": null }`. The API key is never transmitted to the browser.
7. **Display, Edit & Copy:** The frontend populates the message textarea, displays the source badge (`● Generated by AI` or `○ Generated by Template Fallback`), and lets the operator edit before clicking "Copy to Clipboard", which triggers `navigator.clipboard.writeText()` and displays a 2-second "Copied!" confirmation.
   - Implements `prd.md > The Core Journey` (Steps 5 & 6) and `prd.md > 4. Message Editing & Clipboard Copy`.
8. **Add Lead & Reset:** The operator can click "Add Lead" to open a modal form that validates and appends a new lead (evaluated through the canonical triage rules), or click "Reset Sample Data" to clear `localStorage` and reload the seeded leads.
   - Implements `prd.md > The Core Journey` (Step 7) and `prd.md > 5. Manual Lead Creation & Lean State Management`.

## Stack
- **Language / Runtime:** Python 3.12+ (Backend), ECMAScript 2022+ / Vanilla JS (Frontend).
- **Backend Framework:** [FastAPI](https://fastapi.tiangolo.com/) (v0.115+) with [Uvicorn](https://www.uvicorn.org/) (v0.30+) for asynchronous HTTP serving and static file delivery.
  - *Rationale:* Native support in Python, lightning-fast execution, auto-generated OpenAPI docs, and trivial static file mounting.
- **AI Integration:** [google-genai](https://pypi.org/project/google-genai/) SDK or standard HTTP client (`httpx` / `requests`) targeting Google Gemini REST API.
  - *Model Configuration:* `GEMINI_MODEL` environment variable (defaults to `gemini-2.5-flash`, with `gemini-1.5-flash` or `gemini-2.0-flash` as documented alternatives).
  - *Rationale:* Official Google GenAI client for Gemini models; clean error handling with immediate fallback catch.
- **Testing:** [pytest](https://docs.pytest.org/) for automated unit testing of triage rules, metric counts, and fallback generation.
- **Configuration & Secrets:** [python-dotenv](https://pypi.org/project/python-dotenv/) to securely load `.env` on startup.
- **Frontend Framework:** Vanilla JavaScript with modern HTML5 and responsive CSS3.
  - *Rationale:* Zero compilation or bundler steps required; no `node_modules` build friction; guarantees instant launch and zero version drift during live demo recording.
- **Styling & Icons:** Bespoke CSS leveraging modern CSS variables aligned to the PRD palette (`#0F172A`, `#F8FAFC`, `#2563EB`, amber, crimson).

## Where It Runs and How Someone Tries It
- **Runtime Environment:** Runs locally on Windows, macOS, or Linux with Python 3.10+.
- **Environment Configuration:**
  - Create a `.env` file from `.env.example`:
    ```bash
    cp .env.example .env
    ```
  - Set `GEMINI_API_KEY` and optional `GEMINI_MODEL` inside `.env` (if omitted, the app operates 100% reliably in deterministic template fallback mode).
- **Setup & Launch Command:**
  ```bash
  pip install -r requirements.txt
  python main.py
  ```
  The app starts at: `http://127.0.0.1:8000`.
- **Test Command:**
  ```bash
  pytest
  ```
- **Demo Recording Procedure:**
  1. Open `http://127.0.0.1:8000` in Google Chrome or any modern browser.
  2. Observe the top summary cards and preloaded leads.
  3. Select *Marcus Vance* (High Priority quote).
  4. Click "Generate Follow-up Message" to see the tailored draft and generation badge.
  5. Edit a word and click "Copy to Clipboard" to show the "Copied!" feedback.
  6. (Optional) Click "Add Lead" to show dynamic triage on a newly entered lead.

## Components

### Backend API Server (FastAPI)
- **Role:** Coordinates API requests, serves static frontend assets, and keeps API keys secure.
- **Endpoints:**
  - `GET /api/leads` -> Returns the initial 5 seeded sample leads, each enriched with triage classification and diagnostic rationale.
  - `POST /api/triage` -> Evaluates an array of leads using the canonical triage engine and returns enriched leads plus summary metrics.
  - `POST /api/generate` -> Accepts `{ lead: LeadData, tone: str }`, handles Gemini AI generation or template fallback, and returns `{ message: str, source: str }`.
  - `GET /api/health` -> Returns system status, configured model, and whether Gemini API key is configured.
  - `GET /` -> Serves `static/index.html`.
- **PRD Ref:** Implements `prd.md > Screens and Layout` and `prd.md > States and Boundaries`.

### Canonical Lead Triage & Metrics Engine (`triage.py`)
- **Role:** Single source of truth for deterministic triage rules and metric calculations.
- **Rules:**
  ```python
  # High Priority: status == "Quote Sent" and elapsed_days >= 3
  # Needs Follow-up (Standard):
  #   (status == "New Inquiry" and elapsed_days >= 2) OR
  #   (status == "Quote Sent" and 2 <= elapsed_days < 3)
  # No Follow-up Needed:
  #   status in ["Followed Up", "Won", "Lost"] OR elapsed_days < 2
  ```
- **Metric Definitions:**
  - `high_priority_count`: Count of leads meeting High Priority criteria.
  - `needs_followup_count`: Total count of all actionable leads (`high_priority_count` + standard Needs Follow-up). High Priority is strictly an urgent subset of Needs Follow-up.
- **Diagnostic Reason generation:** Every lead receives an explicit string:
  - High Priority Quote: `"Quote unanswered for {days} days"`
  - Overdue Inquiry: `"Inquiry inactive for {days} days"`
  - Recent Quote: `"Recent quote sent ({days} days ago)"`
  - Closed / Won: `"Service booked / won"`
- **PRD Ref:** Implements `prd.md > 1. Deterministic Lead Triage & Urgency Rules`.

### Message Generation Engine (`generator.py`)
- **Role:** Produces personalized outreach messages via Gemini API with deterministic fallback.
- **Model Resolution:** Reads `os.environ.get("GEMINI_MODEL", "gemini-2.5-flash")` (or `gemini-1.5-flash`).
- **AI Mode:** Formats prompt instructing Gemini to act as a professional assistant for a home-services business, generating a polite, concise (2–4 sentence) follow-up tailored to customer name, service, inactive time, notes, and requested tone.
- **Fallback Mode:** Deterministic dictionary of string templates with slots `{name}`, `{service}`, `{days}`, `{notes}` for the three tones:
  - *Friendly Check-in:* "Hi {name}, hope your week is going well! I'm just checking in regarding the {service} we discussed. Please let us know if you have any questions or if you'd like us to schedule a time."
  - *Gentle Nudge:* "Hi {name}, following up on your {service} inquiry from a few days ago. We're currently planning our upcoming service schedule and wanted to make sure you still have a spot reserved if needed."
  - *Value-Focused:* "Hi {name}, just wanted to follow up on your {service} quote. All our work includes our full satisfaction guarantee and certified technician inspection. Let us know if you'd like to move forward!"
- **PRD Ref:** Implements `prd.md > 3. Dual-Mode Follow-up Message Generation`.

### Frontend Single-Page Dashboard (HTML/CSS/JS)
- **Role:** User interface presenting the split layout, summary metrics, lead list, detail panel, message generator, and copy feedback.
- **Files:** `static/index.html`, `static/style.css`, `static/app.js`.
- **PRD Ref:** Implements `prd.md > Screens and Layout`, `prd.md > Look and Feel`, and `prd.md > 4. Message Editing & Clipboard Copy`.

### State & Storage Layer (localStorage + Reset Sample Data)
- **Role:** Stores lead state across page refreshes using browser `localStorage` under key `lead_rescue_leads`. If cleared or on first load, falls back to the seeded list.
- **PRD Ref:** Implements `prd.md > 5. Manual Lead Creation & Lean State Management`.

   - Web framework and ASGI server.

## Important Failure Modes
1. **Missing or Invalid `GEMINI_API_KEY`:**
   - Failure: Server fails to authenticate with Gemini API.
   - Fallback: Generator immediately logs a warning, switches to template fallback mode, and returns `{ "message": "...", "source": "fallback" }`. The UI displays `○ Generated by Template Fallback` without throwing an error to the user.
2. **Network Offline / Disconnected:**
   - Failure: API call to Google times out or network drops.
   - Fallback: Handled gracefully by the backend exception handler, falling back to template generation within milliseconds.
3. **Empty Lead List:**
   - Failure: User deletes all leads in the interface.
   - Fallback: Dashboard displays an informative empty state message with a one-click button to "Reset Sample Leads".

## Automated Test Plan (`test_triage.py`)
1. **High Priority Lead Test:** Quote Sent with $\ge 3$ days elapsed $\rightarrow$ `urgency == "high"`, reason contains "Quote unanswered".
2. **Needs Follow-up Lead Test (Inquiry):** New Inquiry with $\ge 2$ days elapsed $\rightarrow$ `urgency == "medium"`, reason contains "Inquiry inactive".
3. **Needs Follow-up Lead Test (Quote):** Quote Sent with 2 days elapsed $\rightarrow$ `urgency == "medium"`.
4. **Recent Lead Test (No Follow-up):** Quote Sent or New Inquiry with $< 2$ days elapsed $\rightarrow$ `urgency == "none"`.
5. **Closed Lead Test:** Status `Won`, `Lost`, or `Followed Up` $\rightarrow$ `urgency == "none"`, regardless of elapsed days.
6. **Summary Metric Consistency:** Assert `high_priority_count <= needs_followup_count`, confirming High-Priority is strictly an urgent subset of total Leads Needing Follow-up.
7. **Template Fallback Verification:** Assert that `generate_message` produces complete, non-empty text for all three tones with no API key provided.

## What Was Simplified and Why
- **Canonical backend triage with `/api/triage`:** Avoids duplicated triage math in both languages; frontend delegates lead evaluation to the tested Python engine.
- **Vanilla JS instead of Vue/Vite build pipeline:** Eliminates Node build scripts, bundling errors, and development server synchronization, allowing the whole app to run from a single `python main.py` command.
- **localStorage instead of SQLite/PostgreSQL:** Eliminates database schema setup, migrations, and file permissions, while retaining seamless state persistence between page reloads.
